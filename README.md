#  MealMate — AI Fitness & Nutrition App

##  Overview

MealMate is a high-fidelity AI-powered fitness and nutrition mobile application designed to help users track meals, monitor workouts, and receive personalized dietary recommendations.

The application dynamically adapts calorie targets, macronutrient distribution, and meal suggestions based on user biometrics, activity levels, and fitness goals.

A live interactive prototype has been developed using **Lovable** to simulate a real-world AI-driven fitness coaching experience.

## Problem Statement

Most fitness applications:
- Provide static calorie and macro targets
- Lack personalization based on body composition
- Do not integrate nutrition and gym tracking effectively
- Offer limited AI-driven guidance

MealMate addresses these issues through an adaptive AI-based fitness system.

---

## Key Features

### Personalized Onboarding
- User inputs: age, weight, height, activity level, goals
- Dynamic calculation of BMR and TDEE
- Personalized calorie and macro targets

### Nutrition Dashboard
- Real-time calorie tracking
- Macro progress visualization
- Animated UI updates when meals are logged

### AI Meal Suggestions
- Ingredient-based meal generation
- Phase-aware recommendations (Bulk / Lean Bulk / Cut)
- Macro-balanced outputs

###  Gym Tracking
- Exercise logging system
- Strength progression tracking
- Performance visualization

### AI Phase Advisor
- Suggests fitness phase based on user trends
- Dynamically updates nutrition targets
- Confidence-based AI recommendations
